# 首页动态光景

首页横幅复用 [bas3line/ascii](https://github.com/bas3line/ascii) 的 ASCII 场景。
默认极光峡湾，右下角“光景”按钮可打开分类、搜索、随机和播放控制。
场景与手动暂停状态保存在访客自己的浏览器中。

配置入口：`src/config/asciiBannerConfig.ts`。

- `enable: false`：恢复原图片与首页标题横幅。
- `defaultScene`：首次访问使用的场景 ID。
- `maxFps`：帧率上限，默认 15。
- `groups`：场景名称、分类及顺序。

78 个场景作为本地模块按需加载，不请求第三方 API。
离开首页、切到后台或滚出画面时停止动画；系统开启“减少动态效果”时默认静止，访客可以主动播放。
文章页继续使用原横幅。无 JavaScript 或首次加载失败时显示原图片。

上游版本及 MIT 许可见 `src/vendor/ascii-rest/README.md` 与 `LICENSE`。
修改后运行 `pnpm check`、`node --experimental-strip-types --test tests/ascii-scenes.test.mjs`
和 `pnpm build`。推送 main 后，GitHub Actions 自动发布到 GitHub Pages。
